# fadada-document-sign

法大大电子签全生命周期：合同发起、流程查询、撤回与下载。

## 安装

从 GitHub 装（需要本机有 `git`）：

```bash
npx skills add SeaWork-Labs/fadada-document-sign#v1.0.4 --skill fadada-document-sign
```

从市场索引装（纯 HTTPS，国内网络可达）：

```bash
npx skills add https://skills.seaharness.cn --skill fadada-document-sign
```

## 内容

技能正文在 `skills/fadada-document-sign/payload/`。这些文件由转换器从市场归档逐字节搬来，改动请直接改 `skills/fadada-document-sign/payload/`，不要反向同步。版本以 git tag 为准。
